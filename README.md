# Luke Alarm Clock — Privacy Notice

Last updated: 15 November 2026

## About this project
Luke Alarm Clock is a personal, experimental alarm-clock project
developed by GitHub user lukewhe16-maker. It is currently intended only for the
developer’s own use.

## Data accessed
With account authorisation, the prototype accesses WHOOP sleep,
recovery, physiological cycle and workout records. It also records
heart-rate measurements received directly over Bluetooth.

If additional permissions are enabled, it may access profile
information and body measurements.

## Purpose
Data is used to investigate sleep patterns, test experimental
wake-time algorithms and prepare personal morning summaries.

## Storage and sharing
Downloaded records and Bluetooth recordings are stored in the
developer’s project folder. This folder is currently within
OneDrive and may therefore be synchronised to Microsoft’s cloud,
depending on OneDrive settings.

Recorded health data and credentials are excluded from the project's
Git repository. This public repository contains only this notice.

The prototype does not currently send health data to an external
AI service or sell it to third parties.

## Retention and deletion
Records are retained until the developer deletes them. Deleting
cloud-synchronised records may also require removing copies from
cloud storage and its recycle bin.

## Account access
WHOOP access can be revoked through WHOOP’s connected-app settings.
Revoking access does not automatically delete previously downloaded
records.

## Changes
This notice will be updated before introducing new uses or sharing
of personal data.

## Contact
